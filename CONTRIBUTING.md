# Help make tivr better

The best feedback starts with a real task. Explain what you were trying to do, what got in your way, and what would make the next attempt easier.

## Report a problem

Search [existing reports](https://github.com/cquark7/tivr-community/issues) first. If the problem is new, [open a bug report](https://github.com/cquark7/tivr-community/issues/new?template=bug_report.yml) with:

- The tool name or page link.
- A few steps we can follow, with a small invented example when useful.
- What you expected and what happened instead.
- Your browser and whether you were using a desktop, phone, or tablet.

## Suggest a feature or tool

[Share your idea](https://github.com/cquark7/tivr-community/issues/new?template=feature_request.yml). Explain the task, what is missing, and how the improvement would help. You can also add a 👍 to an existing request instead of opening a duplicate.

Requests are considered alongside correctness, privacy, performance, and the effort to maintain them. A request does not guarantee implementation or a response date.

## Keep it useful and considerate

Be kind, stay relevant, and give other people room to explain their needs. Small reproducible examples, documentation corrections, and browser compatibility reports are all useful contributions.

Everything posted on GitHub is public. Use invented data, remove sensitive information from screenshots, and check whether a share link contains your document or code snippet. No tool inputs or diagnostics are attached automatically; GitHub handles what you submit under its own policies.

For direct feedback, email **[contact@tivr.dev](mailto:contact@tivr.dev)**. Please report vulnerabilities using the [private security-reporting guidance](README.md#report-a-security-concern-privately).
