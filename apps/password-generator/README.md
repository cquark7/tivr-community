# Password Generator

Create strong passwords and memorable passphrases in your browser, with no connection needed.

**[Open Password Generator →](https://tivr.dev/password-generator)** · [Explore all tivr tools](../../README.md#find-your-next-tool)

## What you can do

- Random passwords or memorable Diceware passphrases.
- Misreadable characters (0/O, 1/l/I) are left out.
- Live strength meter with an entropy estimate.
