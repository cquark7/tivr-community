# Parquet Viewer & SQL

Open Parquet files and page through their rows right away, with real SQL on tap when you need to filter or join.

**[Open Parquet Viewer & SQL →](https://tivr.dev/parquet-viewer-sql)** · [Explore all tivr tools](../../README.md#find-your-next-tool)

## What you can do

- Rows appear as soon as a file is dropped - paging and sorting need no query.
- Run SQL joins, filters, and aggregations across several dropped files.
- Pin columns, adjust text size, and export any page or result as CSV.
