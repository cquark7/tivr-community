# Monty Playground

Run the new Monty 1.0 Python interpreter in a browser sandbox, and keep the session between runs.

**[Open Monty Playground →](https://tivr.dev/monty-playground)** · [Explore all tivr tools](../../README.md#find-your-next-tool)

## What you can do

- Globals persist between runs, so a second snippet picks up where the first left off.
- Says which Python it cannot run before the run, instead of failing halfway through.
- Rewind or branch a session to retry a line with the earlier values still in place.
