# Markdown Editor

Write Markdown and see a formatted preview update as you type.

**[Open Markdown Editor →](https://tivr.dev/markdown-preview)** · [Explore all tivr tools](../../README.md#find-your-next-tool)

## What you can do

- Mermaid diagrams, tables, and task lists render live.
- Keyboard shortcuts for bold, italic, code, and strikethrough.
- Share a draft as a link, with the text carried in the URL alone.
- Live word and character counts.

## Make it work better for you

Something getting in your way? [Report a bug](https://github.com/cquark7/tivr-community/issues/new?template=bug_report.yml&tool=Markdown+Editor) or [suggest an improvement](https://github.com/cquark7/tivr-community/issues/new?template=feature_request.yml&tool=Markdown+Editor). A small, invented example helps clarify the issue.

Files and text are processed on your device and never uploaded. For storage details and other privacy choices, see the [tool's FAQ](https://tivr.dev/markdown-preview) and [tivr's privacy page](https://tivr.dev/privacy).
