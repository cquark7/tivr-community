# PDF Password Remover

Remove a known password from a PDF and save an unlocked copy, without sending the document anywhere.

**[Open PDF Password Remover →](https://tivr.dev/pdf-unlocker)** · [Explore all tivr tools](../../README.md#find-your-next-tool)

## What you can do

- Unlocks PDFs up to 500 MB.
- Preview the document before you save it.
