# JSON Formatter

Format JSON, find errors, and explore nested data without changing your numbers or losing duplicate keys.

**[Open JSON Formatter →](https://tivr.dev/json-formatter)** · [Explore all tivr tools](../../README.md#find-your-next-tool)

## What you can do

- Large numbers, string escapes, and duplicate keys stay intact.
- Search the tree, copy a path, or extract a subtree.
- Preview repairs before applying them, with undo for every change.
- JSON, JSON with comments, and JSON Lines are supported.
