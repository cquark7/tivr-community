# Text Compare

Compare two versions of text and see exactly what changed.

**[Open Text Compare →](https://tivr.dev/diff-checker)** · [Explore all tivr tools](../../README.md#find-your-next-tool)

## What you can do

- Long runs of unchanged lines collapse automatically.
- Compare by line, word, or character.
- Ignore whitespace-only changes and letter case.
- Copy or download the result as a .patch file.

## Make it work better for you

Something getting in your way? [Report a bug](https://github.com/cquark7/tivr-community/issues/new?template=bug_report.yml&tool=Text+Compare) or [suggest an improvement](https://github.com/cquark7/tivr-community/issues/new?template=feature_request.yml&tool=Text+Compare). A small, invented example helps clarify the issue.

Files and text are processed on your device and never uploaded. For storage details and other privacy choices, see the [tool's FAQ](https://tivr.dev/diff-checker) and [tivr's privacy page](https://tivr.dev/privacy).
